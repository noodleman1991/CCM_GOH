# CCM Hub — Editor Guides

Editor-facing guides for using the Sanity CMS to publish content on the hub.
Saved here from local files that were previously only in `~/Downloads` (never
tracked in git).

## Files

- **`ccm-cms-editor-guide-news-posts.html`** — *"CCM CMS · Editor's Guide — News Posts"* (authored 2026-05-20). The current, most recent editor guide: how the CMS is organised, publishing a News Post step-by-step, how translations behave, a field cheat-sheet, a pre-publish checklist, and common pitfalls. Open in a browser.
- **`ccm-cms-manual.html`** — a shorter companion draft (2026-05-19). Kept for reference.
