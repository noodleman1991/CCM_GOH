## 2. Infrastructure gaps that block production (ranked)

1. **Outbound email is sent from Resend's sandbox sender.** `CASE_STUDY_EMAIL_FROM` is unset in Vercel production (verified via `vercel env ls`); all four senders fall back to `onboarding@resend.dev` (`lib/case-study-emails.ts:19`, `lib/comment-notifications.ts:5`, `lib/notifications/email.ts:6`, `lib/issue-report-email.ts:12-14`). The domain is verified, so the fix is one variable: `CASE_STUDY_EMAIL_FROM="Connecting Climate Minds <hub@connectingclimateminds.org>"` on Production and Preview. Pair with Slice 2 (code reads the `{error}` result) or the failures stay invisible.
2. **Production is 4 weeks stale.** Deployment `a8ad0c5` (2026-08-15) predates Turnstile, the security slices from 2026-08-18, and everything in this branch. Anonymous comments fail with a misleading message today. Fix: preview deploy after Slice 0, production deploy after Slices 1–3.
3. **No error monitoring.** `NEXT_PUBLIC_SENTRY_DSN` absent in Development/Preview/Production; `instrumentation.ts:29` returns before init. Fix: create the Sentry project; set `NEXT_PUBLIC_SENTRY_DSN`, `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_PROJECT`; add the last two to `.env.example`. Code side (error boundaries) in Slice 11.
4. **Newsletter 500s on every submit.** `RESEND_AUDIENCE_ID` blank in every env incl. Vercel (`app/api/newsletter/route.ts:19-25`). Fix: either create the audience and set the var, or remove the `form-newsletter` block from live pages until double opt-in exists (Decision 10). Also unblocks the erasure step at `lib/account-deletion.ts:355`.
5. **`INTERNAL_SYNC_SECRET` absent from the prod-mirror `.env`** (Vercel unverified). With it unset, `Authorization: Bearer undefined` authenticates full re-index against every live index (`app/api/search/*/sync/route.ts`). Fix: set it in Vercel + code fix in Slice 3 that refuses when unset.
6. **Environment manifest is wrong.** `lib/env.ts:16-17` checks `ALGOLIA_ADMIN_KEY` and `CLOUDFLARE_R2_*`, names the code does not read (`lib/algolia.ts:18`, `lib/r2.ts:16-18`), so the boot report lies both ways; `.env.example` omits 15 read variables (`ADMIN_API_KEY`, `ALGOLIA_APP_ID`, `ALGOLIA_INDEX_PREFIX`, `CONTENT_BACKEND` + 17 domain switches, `NEXT_PUBLIC_APP_URL`, `OPENALEX_MAILTO`, `ORCID_API_BASE`, `PAYLOAD_REVALIDATE_SECONDS`, `SANITY_REVALIDATE_SECONDS`, `R2_PUBLIC_URL`, `SENTRY_ORG`, `SENTRY_PROJECT`) and documents 5 dead ones (`CLOUDFLARE_R2_ACCOUNT_ID/PUBLIC_URL/REPORT_BUCKET/REPORT_PUBLIC_URL`, `SANITY_API_WRITE_TOKEN` — the code reads `SANITY_API_EDITOR_TOKEN`). Fix in Slice 1.
7. **Payload production boot has no assertions.** `PAYLOAD_DATABASE_URL`/`PAYLOAD_SECRET` default to `""` (`payload.config.ts:56,188`). Blocks only once `CONTENT_BACKEND` flips; add to a `REQUIRED_WHEN_PAYLOAD` list in Slice 1.
8. **`NEXT_PUBLIC_APP_URL` is a third base-URL variable** (`.env:81` points local dev at production). Retire it with the add-work pages in Slice 7; consolidate on one `siteUrl()` helper in Slice 10.
9. **Vercel plan tier** for the hourly `event-reminders` cron (`vercel.json:7`) is unverified; weekly crons and 300s duration are within Hobby. Check the Cron Jobs tab once; not a code item.
10. Not blocking, for the record: `CRON_SECRET` and both Turnstile keys are present in Vercel; `R2_*` present in `.env` (prod), absent locally; `SEARCH_WEBHOOK_SECRET` present in `.env`, absent in `.env.local` (dev re-index 401s silently); `NEXT_PUBLIC_ALGOLIA_SEARCH_API_KEY` is invalid but only a fallback.
